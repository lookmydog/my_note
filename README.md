### Zettelkasten 卡片盒筆記 (My Note)
### 這是一個極簡且功能強大的「卡片盒筆記」應用程式。所有的程式碼、樣式與邏輯都集中在一個 HTML 檔案中，無需任何安裝或伺服器設定，用瀏覽器打開即可立刻使用！

✨ 主要特色
* 開箱即用：採用純前端技術（React + Tailwind CSS + D3.js）打造的單檔 (Single-file) 應用。

* 視覺化圖譜：內建互動式關係圖譜，輕鬆鳥瞰筆記之間的連結與知識網絡。

* 流暢的編輯體驗：支援 Markdown 渲染、自訂標籤 (Tags)，並內建多種實用模板（日記、專案、文獻等）。

* 資料隱私與備份：筆記完全儲存於瀏覽器本地端 (Local Storage)，並支援 JSON 格式的備份匯出與匯入。

🚀 如何開始
只需將本專案的 HTML 檔案下載至電腦，使用任何現代瀏覽器開啟，就能馬上開始建構你的個人知識庫。
